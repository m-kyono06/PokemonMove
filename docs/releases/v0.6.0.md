## 下画面で操作、上画面でポケモンを表示

RGDS・今後のAYN Thor利用を想定した、独立2画面対応を追加しました。

1. ホーム右上メニュー →「2画面設定」
2. 操作を下画面、表示を上画面に割り当てて「2画面モードを開始」
3. 上下が逆なら「上下を入れ替える」後に開始
4. 下画面でポケモンを選ぶと上画面へ連動

- 上画面：通常色／色違いの代表画像、名前、レベル、タイプ、性格、特性、もちもの、能力値、技を表示します。
- 下画面：選択・保管・引き出しを操作します。選択だけでは移動せず、専用ボタンと確認後に実行します。
- 図鑑から選択した場合は、上画面に個体の能力値ではなく種類の画像と所持状況を表示します。
- アプリを離れると上画面を閉じ、戻ると再表示します。1画面時や移動を拒否された場合は通常画面で続行できます。
- 画像は986枚を同梱し、通信なしで表示します。今回は静止画です。3D、フォルム・性別ごとの専用画像は未実装です。
- 操作画面の切り替えではホームに戻ります。登録済みセーブやバンクは保持します。

Android APIによる実装・割当と選択状態のテスト・APKビルドを確認しています。RGDS・Thor実機での画面起動と連動の確認はこれからです。
