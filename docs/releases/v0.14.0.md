## バンク内の通信進化

バンク内で個体を選び、「選択したポケモンを通信進化」から進化を実行できるようになりました。ネットワーク通信や別の端末は不要です。引き出し時には自動で進化しません。

- 第4〜第7世代の保存形式ごとの通信進化に対応。ユンゲラー→フーディン、ゴースト→ゲンガー、ゴーリキー→カイリキーなど。
- ハガネール・ハッサム・キングドラ・ポリゴン2・ポリゴンZ・ハンテール／サクラビスなど、持ち物が必要な進化では正しい道具を確認し消費します。道具は先に元のゲーム内で持たせてから移動保管してください。
- ガントル・ドテッコツ、ヒンバス＋きれいなウロコは第5世代以降。シュシュプ・ペロッパフ・ボクレー・バケッチャは第6世代以降。
- カブルモとチョボマキは同じ保存世代の相手を選び、両方を同時に進化させます。
- アローラのゴローン、バケッチャのサイズを保持します。
- タマゴ、旧版のコピー保管、中断移動中は実行できません。かわらずのいしは進化を止めます（第4〜第7世代のユンゲラーは例外で、石も保持）。

PID・親ID・性格・性別・色違い・個体値・努力値・経験値・レベル・技・PPを保持し、特性は進化後の同じ特性枠へ更新します。ニックネームがなければ進化後の種名へ変更します。親や出身情報は変更せず、通信進化のみを再現します。進化時の技は自動習得しないため、必要に応じてゲーム内の技思い出しを利用してください。

進化先と道具の消費は実行前に確認します。進化前の個体は進化後へ置き換えられ、元には戻せません。進化前のバンクを内部バックアップへ保存し、1匹／2匹の置き換えと消費済み履歴を同時に保存します。古いバックアップを取り込んでも進化前の個体を増やせません。進化後と同じデータがすでにバンクにある場合も重複を作らず拒否します。

進化後は通常どおりセーブへ引き出せ、アプリ内の収集図鑑にも反映されます。セーブは引き出すまで変更しません。バンク形式はバージョン5のままです。

生成データで全進化ルート、姿・特性枠・道具、古いバックアップの再取り込み、保存失敗時に元の個体が保持されること、進化後の引き出しを確認しています。エミュレータ・実機での動作は未確認です。

**更新前にバンクと登録一覧を外部へバックアップし、中断した移動は先に復旧してください。** デバッグ署名の違いで旧版削除が必要になる場合があります。再インストール後はバックアップを取り込み、登録セーブへ接続し直してください。

Android 8.0以降・arm64向け開発版。GPL-3.0-or-later（フォントはOFL 1.1）。
