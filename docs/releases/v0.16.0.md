## 既存個体の色違い化

ホームで読み込んだ手持ち・ボックスの個体を選び、「選択した個体を色違いにする」から実行できます。

**ポケモンの新規作成は追加していません。** 空き枠への生成、複製、バンクへの追加も行いません。すでに色違いの個体やタマゴは対象外です。

- 第4〜第7世代・対応17作品の手持ち／ボックスに対応。
- 性格・性別・特性枠・親ID・個体値・努力値・個性・技・PP・持ち物・出会った情報などを保ち、色違い判定に必要なPIDを変更。
- HP・状態異常・PPを勝手に回復しません。個体数・他の枠も維持。
- 第4・第5世代のパッチールはPIDによる模様の変化を確認画面で案内。ケムッソ系統の進化分岐は維持します。
- 第6・第7世代では暗号化定数を維持。
- バトルチーム・ポケリゾート内・合体中などの保護対象は拒否。先にゲーム内で解除してください。

変更前のセーブ全体をバックアップしてから書き込み、書き込み後に内容を照合します。変更前のバックアップはバンク画面から書き出せます。書き込みが中断した場合は「中断した操作を復旧する」から同じセーブを選びます。バンクの個体や引き出し権限は追加・消費しません。

バンク形式はバージョン5のままですが、色違い化の中断処理の復旧にはv0.16.0以降が必要です。中断したまま旧版へ戻さないでください。ゲーム内図鑑フラグは変更せず、アプリの収集図鑑は次回の更新時に反映します。

**セーブ編集による色違い化です。正規入手の個体としての整合性は保証できません。** エミュレータを終了し、実際にゲームが使うセーブへ適用してください。

生成データで全17作品の手持ち・ボックス、全性格とPIDに結び付く属性、HP・状態異常の保持、書き込み前・途中・後の中断復旧、空き枠や変更済みファイルの拒否を検証しています。実機・ゲーム内での色違い化は未確認です。

**更新前にバンクと登録一覧を外部へバックアップし、中断した操作は先に復旧してください。** デバッグ署名の違いで旧版削除が必要になる場合があります。再インストール後はバックアップを取り込み、登録セーブへ接続し直してください。

Android 8.0以降・arm64向け開発版。GPL-3.0-or-later（フォントはOFL 1.1）。
