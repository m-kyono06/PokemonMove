## HGSS チェックサム判定の修正

- 表示に使わない追加領域（バトルビデオなど）だけの不一致で、セーブ全体を拒否していた判定を変更しました。
- 主人公・手持ち・ボックスの有効なセーブブロックは引き続き検証し、不一致なら読み込みを止めます。
- 追加領域の不一致は画面に警告を表示します。元のセーブは変更しません。
- 読み込めない場合は、エラーに不一致の領域と診断情報を表示します。

DraStic／ソウルシルバーでの報告を受けた修正です。報告された実ファイルは未確認のため、解消は再テストが必要です。

## インストール

Android 8.0 以降・arm64 端末向け。添付の PokemonMove-v0.1.1-android-arm64.apk をインストールしてください。
GitHub Actions によるデバッグ署名版です。署名が異なると表示される場合は、旧版をアンインストールしてから入れ直してください。現在のアプリにバンク保存機能はありません。

バンク・移動・収集図鑑・3DS作品は未実装です。通常セーブ（.sav／対応する .dsv）の読み取り専用です。

GPL-3.0-or-later。PokemonMove と PKHeX.Core 26.10.18 の対応ソースを添付しています。ビルド手順は README.md を参照してください。
