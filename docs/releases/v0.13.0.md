## 第4〜第7世代の逆方向移動

第5世代生まれの個体も、第4世代に存在する種類・姿などの条件を満たせば移動できるようになりました。第6・第7世代からも対応します。

| 移動元 | 新たに対応する移動先 |
| --- | --- |
| BW・BW2 | D・P・Pt・HGSS |
| XY・ORAS | D・P・Pt・HGSS、BW・BW2 |
| サン・ムーン・USUM | D・P・Pt・HGSS、BW・BW2、XY・ORAS |

先にバンクへ移動保管し、引き出し先の古い作品を選んでください。「非公式の逆方向変換を確定」に変更内容を表示し、「逆方向変換して移動」で実行します。

### 引き継ぐ情報と制限

- 種類・姿・親ID・親名・性別・性格・色違い・個体値・努力値・技を保持します。特性は同じ特性になる移動先の枠へ設定します。
- 移動先に存在しない種類・フォルム・技・思い出せる技・特性・ボールは拒否し、バンクに残します。特性は移動先のその種・姿にも存在する必要があります。
- 隠れ特性は第4世代へ持ち込めません。タマゴは孵化、持ち物は元のゲーム内で外してください。長すぎる名前・対応しない文字や言語も自動で書き換えず拒否します。
- 以前の仕様で性格・性別・特性枠・色違いを保つためPIDを調整する場合があります。その際はPIDによる模様・進化分岐が変わる可能性を案内します。

### 変換で変更・消失する情報

**公式には存在しない変換です。正規個体としての整合性を保証する機能ではなく、元の個体データへ復元する機能でもありません。**

- 出身作品は移動先形式の代表作品（D／Pt／HG／B／B2／X／OR）相当になります。
- 出会った場所は未設定、出会ったレベルは現在のレベル、日付は変換日になります。
- 経験値は現在レベルの開始値に合わせ、PPは回復します。能力値は移動先の仕様で再計算します。
- リボン・配布フラグ・コンテスト・マーキング・思い出・なかよし度・すごいとっくん・元の孵化記録などの追加記録は引き継ぎません。すごいとっくんの効果も失われ、生の個体値で計算します。
- 第4・第5世代には思い出せる技の専用記録や暗号化定数を引き継げません。親IDの表示方式も以前の世代に合わせます。

同世代内は従来どおり保存バイト列を保持します。順方向の第4→第5、第5→第6、第6→第7世代の移動も引き続き利用できます。順方向で中間世代を飛ばす場合は従来どおり中間作品を経由してください。

バックアップ→書き込み→照合成功→バンクから消費の手順、元セーブからの除去、中断復旧は従来どおりです。バンク形式はバージョン5から変更しません。

生成データで全17作品の新しい世代→古い世代108通り、全6方向の書き込み前・部分書き込み・書き込み後の中断復旧、全25性格・色違い判定差・不適合個体のバンク保護を確認しています。実際のエミュレータ・ゲーム内での逆方向移動は未確認です。GBA以前・VC・Switch作品は対象外です。

**更新前にバンクと登録一覧を外部へバックアップし、中断した移動を先に復旧してください。** デバッグ署名の違いで旧版削除が必要になる場合があります。再インストール後はバックアップを取り込み、登録セーブへ接続し直してください。
