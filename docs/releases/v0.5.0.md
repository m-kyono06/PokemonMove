## すべての登録セーブを図鑑で集計

- SSを開いた後にHGを開いても、両方を図鑑の集計対象として保持します。
- 登録一覧はアプリ再起動後も残り、図鑑の更新時にすべての登録セーブを読み直してバンクと合算します。
- 引き出し先として読み込んだセーブも登録します。
- ポケモンの詳細ではセーブ別の所持数を確認できます。同じ種類は複数のセーブにいても1種類として数えます。
- 「登録セーブを管理」で追加・再接続・集計対象からの解除ができます。解除はセーブやバンクのデータを削除しません。
- 読めない登録を勝手に除外したり、古い所持数を使ったりせず、接続の修正を案内します。
- 図鑑の表示・登録管理で、セーブ本体やバンクを書き換えることはありません。

**更新後にSS/HGをそれぞれ一度開いて登録してください。** v0.4.0以前には登録一覧が保存されていません。
現在の読み込み対応はHGSSのみです。今後の作品対応に向けて、登録・読み込み・集計処理を分離しています。

## バックアップ

更新前にバンクを外部へバックアップしてください。デバッグ署名が異なる場合、旧版の削除が必要になることがあります。
この版以降は、アプリ削除前に「バンク」と「登録一覧」をそれぞれ書き出してください。
一覧にセーブ本体は含みません。再インストール・端末変更後は、一覧を取り込み、各ファイルへ接続し直してAndroidの権限を取り直してください。

Android 8.0 以降・arm64 向けの開発版です。APKは PokemonMove-v0.5.0-android-arm64.apk。
自動テストとAndroidビルドを確認しています。登録管理・複数ファイル再接続の実機での確認はこれからです。
