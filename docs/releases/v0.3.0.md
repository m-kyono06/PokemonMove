## コピー保管から「移動」へ

- 保管時：移動前のセーブをバックアップし、選択した個体をセーブから取り除いて、書き込み照合後にバンクの保管を確定します。
- 引き出し時：選択した HGSS セーブのボックス空き枠へ書き込み、再読込で確認した後にバンクから取り除きます。
- **保管元のセーブにも戻せます。** 引き出し先に同じ個体データがあれば拒否します。
- 中断した移動は記録してロックし、同じセーブとの照合または明示的な復旧で解決します。
- 古いバンクバックアップの取り込みでは引き出し済みの記録を復活させません。移動履歴の巻き戻しはできません。

## 既存データと操作前の注意

- **更新前に v0.2.0 のバンクバックアップを外部へ保存してください。** デバッグ署名が違い、旧版の削除が必要になる場合があります。
- v0.2.0 のコピー保管はそのまま引き出せません。元セーブにある同じ個体を改めて「バンクへ移動」すると切り替わります。
- エミュレータを完全に終了し、実際に使用するセーブを直接選択してください。選択したファイルだけを書き換えます。別のコピーを選ぶと原本には個体が残ります。
- メール付き個体、戦える手持ちが残らない操作、空き枠以外への引き出しは拒否します。
- 中断時は再操作せず、バンク画面で「中断した移動を復旧する」を使ってください。
- 別途保存したバックアップの手動巻き戻し・別端末での並行使用による複製まで防ぐものではありません。

開発環境での失敗・復旧テストと、提供セーブの一時コピーによる同一セーブへの往復を確認しています。Android の実ファイル書き込み画面は実機での確認が必要です。原本や提供されたセーブは配布物に含めません。

Android 8.0 以降・arm64 向けの開発版です。APK は PokemonMove-v0.3.0-android-arm64.apk。GPL-3.0-or-later。対応ソースとチェックサムを添付しています。
