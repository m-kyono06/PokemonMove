## ローカルバンクへの保管

- セーブ内のポケモン詳細から「バンクにコピーして保管」を選べます。
- 元のセーブは変更せず、ポケモン本体のデータをアプリ専用領域に保管します。
- 「ローカルバンクを開く」から一覧・詳細・コピー元を確認し、名前やニックネームで検索できます。
- 同じデータの重複保管を防ぎます。再起動後も保管データを読み込めます。
- バックアップの書き出し・取り込みと、直前の自動バックアップへの復元を追加しました。

これはコピー保管です。ゲームへの引き出し・移動、収集図鑑、3DS作品は今後追加します。

## インストール・データの保護

Android 8.0 以降・arm64 端末向け。PokemonMove-v0.2.0-android-arm64.apk をインストールしてください。
デバッグ署名の開発版です。署名が異なると表示される場合は、旧版を削除してから入れ直してください。
v0.1.x にバンク保存機能はありませんが、**v0.2.0以降を削除する前には必ずバンクのバックアップを書き出し、外部へ保存してください。**

Android実機のバンク画面での操作確認はこれからです。生成データの保存テストと、ユーザー提供セーブによる37匹の一時保管・再読込・バックアップ復元を開発環境で確認しています。実際のセーブは配布物に含めていません。
